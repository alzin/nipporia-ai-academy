よくある質問

プログラミングの経験がなくても大丈夫ですか？

大丈夫です。どの講座も、やってほしいことをふだんの言葉で伝えるところから始めます。「コードを書かずに、自分のサイトを作って公開する」は、プログラミングの経験がない人に向けて作りました。

どの講座から見ればいいですか？

Claude Code を使うのがはじめてなら、「Claude Code 入門」からどうぞ。自分のサイトを作りたい人は、「コードを書かずに、自分のサイトを作って公開する」から始めてもかまいません。アプリの準備がまだなら、入門の第3回と第4回もあわせて見てください。「Claude Code を自分仕様にする」は、入門を見終えてからがおすすめです。

無料で見られるのは、どの回ですか？

どの講座も、約3割の回が無料です。「入門」は第1・4・10・12・15・18回、「自分仕様にする」は第1・2・7回、「自分のサイトを作って公開する」は第1・2・6・9回。登録しなくても見られます。

これから追加される講座も見られますか？

はい。メンバーなら、追加の料金なしで見られます。「今後追加予定」の講座はいま準備しているところで、公開の時期はまだ決まっていません。

コミュニティでは、何ができますか？

質問を投稿したり、ほかのメンバーの投稿にコメントしたりできます。画像や動画もつけられます。投稿やコメントはメンバーだけ、読むのは登録なしでもできます。いまある投稿は、運営が作った見本です。

AI にパソコンのファイルを触らせるのが不安です。

権限モードを「Manual」にしておけば、ファイルを書き換える前に毎回確認してくれます。どこがどう変わるのかを見てから、承認するか拒否するかを選べます。「入門」の第5回で、実際の画面を見ながら説明しています。

パソコンは必要ですか？

動画は、スマホやタブレットでも見られます。ただ、Claude Code を実際に使って練習するには、Windows か Mac のパソコンが必要です。「自分のサイトを作って公開する」では、GitHub のアカウント（無料で作れます）も使います。

アプリの画面が英語でも大丈夫ですか？

ボタンなど、画面の一部は英語で表示されます。動画では、どこを見て、どこを押すのかに印を付けて説明します。Claude Code へのお願いは、日本語で書けます。

Claude の料金は講座の価格に入っていますか？

入っていません。Claude Code を使うには、Claude の有料プランが別に必要です。金額は変わることがあるので、Anthropic の公式サイトで確かめてください。

支払い方法は何がありますか？

クレジットカードで払えます。お支払いは Stripe の決済ページで行います。

申し込んだあと、どうやって見ますか？

お支払いが終わると、そのまま視聴サイトで、すべての講座の全レッスンが見られます。同じメールアドレスでログインすれば、スマホやタブレットからも見られます。

動画はいつまで見られますか？

メンバーでいるあいだは、いつでも見られます。解約しても、次の更新日までは見られます。

解約はどうすればいいですか？

視聴サイトの「サブスクリプション管理」から、いつでも解約できます。解約の手数料はかかりません。

返金はできますか？

デジタルコンテンツのため、お支払い後の返金はしていません。そのかわり、どの講座も約3割の回は登録なしで見られます。続けられそうか確かめてから申し込んでください。こちらの不具合で見られないときは、info@nipporia.com までご連絡ください。

領収書は出ますか？

お支払いのたびに、Stripe から領収書がメールで届きます。宛名など、ほかに必要なことがあれば info@nipporia.com までご相談ください。
